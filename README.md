# 我家 3D 裝潢模擬器

個人與家庭使用的家具配置工具，支援電腦滑鼠與手機觸控。

## 使用方式

登入後使用 2D 平面、3D 空間或第一人稱漫遊查看房間。家具庫以分類呈現，尺寸使用 cm，可新增、改尺寸、旋轉、改色及刪除。我的物品可保存自己的家具資料、參考圖片及模型。

## 配置工具

- 3D 拖家具直接移動，拖空白旋轉視角；雙指縮放和平移。重疊家具可從物件列表選取，開啟移動模式。
- 拖曳時避開牆體，靠近牆面 10 cm 內自動貼齊；部分家具放開時會對齊牆向。
- 測量：點兩個位置，查看平面距離。可吸附牆面及家具邊緣，手機用水平／垂直按鈕，電腦可按 Shift 鎖軸。
- 復原／重做：上方箭頭或 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z；每次拖曳算一筆操作。歷史最多 60 筆，只保留本次頁面，載入不同遠端配置時重設。
- 視角：切換完整牆高／剖面低牆。漫遊時自動顯示完整牆高。
- 配色：全屋底色及房間獨立地板。提供木地板、淺／深磁磚、石材、水泥與純色。

## 保存與共享

修改後等待畫面顯示保存完成。共享成員可重新整理、回到頁面或選擇立即同步取得最新配置。復原後也會保存復原結果。若出現衝突，先保留備份，再依畫面選擇處理方式。

## 適用範圍

這是家具配置模擬工具，並非施工 CAD。測量是平面距離；拖曳以家具目標外框避牆，不是精密網格碰撞，也不阻擋家具互相重疊。手動輸入位置、尺寸及旋轉仍需自行確認空間。

手機版已進行響應式與觸控模擬測試，實體裝置的效能與瀏覽器行為可能不同。
