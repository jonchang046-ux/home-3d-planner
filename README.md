# 我家 3D 裝潢模擬器

個人與家庭使用的家具配置工具，支援電腦滑鼠與手機觸控。

## 使用方式

登入後使用 2D 平面、3D 空間或第一人稱漫遊查看房間。家具庫以分類呈現，尺寸使用 cm，可新增、改尺寸、旋轉、改色及刪除。我的物品可保存自己的家具資料、參考圖片及模型。

## 配置工具

- 3D 拖家具直接移動，拖空白旋轉視角；雙指縮放和平移。重疊家具可從物件列表選取，開啟移動模式。
- 拖曳時避開牆體，靠近牆面 10 cm 內自動貼齊；部分家具放開時會對齊牆向。
- 測量：點兩個位置，查看平面距離。可吸附牆面及家具邊緣，手機用水平／垂直按鈕，電腦可按 Shift 鎖軸。
- 復原／重做：上方箭頭或 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z；每次拖曳算一筆操作。歷史最多 60 筆，只保留本次頁面，載入不同遠端配置時重設。
- 視角：切換完整牆高／剖面低牆。漫遊時自動顯示完整牆高。
- 配色：全屋底色及房間獨立地板。提供木地板、淺／深磁磚、石材、水泥與純色。

## 物品資訊

點選場景中的家具或設備，即可看到資訊摘要與狀態；選擇「新增物品資訊」或「查看／編輯物品資訊」填寫名稱、分類、品牌、型號、購買價格（NT$）、購買／安裝日期、店家來源與備註。名稱沿用家具名稱，其他欄位可留白。狀態包含規劃中、已購買、已安裝、已淘汰。

資訊屬於放入場景的這一件物品，不會改動「我的物品」範本或匯入的模型。按「儲存資訊」後等待上方顯示已儲存至雲端；共享成員可在重新整理或立即同步後看到更新。未儲存的草稿只暫留目前頁面，可返回家具操作後繼續填寫，或捨棄草稿。已套用但尚未同步的修改會沿用既有離線暫存與衝突處理。

刪除家具時，其資訊也會一起從配置移除；本次頁面可用復原取回。已淘汰狀態只作標示，不會自動隱藏物件。保固與維修功能見下方詳細資料；本版尚未提供文件上傳或補貨連動。

## 物品詳細資料、保固與維修

快速資訊卡的「查看詳細資料」提供基本資料、購買資訊、保固資訊、維修／保養紀錄、相關連結與備註。可填寫序號、訂單編號、發票／收據備註、保固開始／到期日、保固月份、客服資訊、說明書與原廠網址。購買店家沿用原本來源欄位；所有新欄位均可留白。

保固依本地曆日計算，距到期 60 天內標示即將到期，到期當日剩 0 天，隔天才過期。月份可按按鈕估算到期日，仍須以條款校正；不會自動覆蓋手動日期。

維修、保養、清潔、零件更換與其他紀錄可各自新增、編輯、確認後刪除。紀錄依日期由新到舊排序，顯示最近一次紀錄與最近未來保養日期；沒有未來日期而仍有過去的預定日時顯示已逾期。已完成或取消的預定日可編輯原紀錄清除。

詳細資訊與每筆紀錄各自儲存；請等完成提示後再離頁。維修紀錄只保存於雲端，網路失敗時保留此頁草稿，待恢復連線再按儲存。刪除家具會隱藏相關紀錄，本次頁面可復原；刪除單筆維修紀錄無法用配置復原取回。現有「配置救援備份」包含家具與保固資料，但尚未包含獨立維修紀錄，也不會替家具救援副本複製維修歷史。

## 雲端保存

修改後等待畫面顯示保存完成。共享成員可重新整理、回到頁面或選擇立即同步取得最新配置。復原後也會保存復原結果。若出現衝突，先保留備份，再依畫面選擇處理方式。

## 適用範圍

這是家具配置模擬工具，並非施工 CAD。測量是平面距離；拖曳以家具目標外框避牆，不是精密網格碰撞，也不阻擋家具互相重疊。手動輸入位置、尺寸及旋轉仍需自行確認空間。

手機版已進行響應式與觸控模擬測試，實體裝置的效能與瀏覽器行為可能不同。

## 垂直擺放與固定設備

- 拖曳物件至足夠大的桌面或櫃面，會自動放上有效頂面；也可在「擺放與安裝」選「物件頂面」並指定支撐物。
- 上方物件跟隨支撐物移動與旋轉。刪除支撐物或支撐面不足時，上方物件回到地板；可用復原還原。
- 壁掛物選「壁掛／手動離地」，輸入「底部離地」公分。鏡子、抽油煙機等移動時保留安裝高度。
- 浴室與廚房設備提供簡化模型。頂天立地衣櫃可改門片樣式與門板顏色，並將高度設到天花板下 1 cm。
- 流理台可選內嵌水槽；有水槽時只提供兩側支撐區。瓦斯爐提供 2／3 口。
- 自訂模型以實際縮放後的外框判斷支撐；請確認頂面平坦後啟用承載。此功能不是物理模擬，不判斷承重或凹凸網格。
- 建築屋頂在剖面規劃時隱藏、完整牆高時透明，漫遊時顯示實體屋頂。

## 擺放補充

自動檯面吸附限制底部高度差在 90 cm 內；較高的承載面可用「物件頂面」明確指定。所有壁掛物都會以背面對齊有效牆面，修改深度後保留原有貼牆位置。浴室設備另提供壁掛洗手台，頂天立地衣櫃位於「固定櫃體／衣櫃」。家具庫的起始尺寸都是一般預設值，可自行修改。
